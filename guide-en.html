2. CV, Rq, Guide RMS and P95

Mean width

The mean distance between the green edges. Each stripe has its own estimate; no target width is assumed for either dose.

Width CV: width consistency

100 × width standard deviation / mean width. Larger overall width variation usually raises CV. A constant-width stripe can bend on both sides while CV stays near zero.

Local edge Rq: local roughness

A moving average creates the orange local trends. Rq is the RMS edge deviation from those trends, combining both edges. A slow bend can be absorbed by the trends and may not produce a high Rq.

Guide RMS: deviation from straight references

The RMS perpendicular distance from each green edge to its blue guide, pooling both edges. It responds to bending, local width changes, and roughness. A global tilt can be accommodated by the fitted direction.

Guide P95: 95th percentile of deviation

Approximately 95% of valid absolute edge deviations are at or below this value. It is not the maximum; a very short defect can fall in the remaining 5%.

RMS: root mean square

Square the deviations, average them, then take the square root. Larger deviations receive more weight, but their duration also matters. Units depend on the metric.

Rq compares edges with local moving-average trends. Guide RMS compares edges with fitted straight lines. These references differ, so the values are not interchangeable.

3. v8: the worst continuous 5% window

Slide a window covering 5% of the analyzed length, advancing one cross-section at a time. Report the largest window RMS for each metric independently. The three worst windows may occur at different locations.

Width variation: worst local width RMS %

Within a window, calculate RMS width deviation from the entire stripe's median width, then divide by that median and multiply by 100. Do not subtract the window's own mean, which could hide sustained narrowing.

Edge deformation: worst local edge RMS %

Within a window, pool squared perpendicular deviations from the left and right blue guides with equal weight, take RMS, then divide by median width and multiply by 100.

Local unevenness: worst local roughness RMS %

Within a window, pool squared left and right deviations from their local moving-average trends with equal weight, take RMS, then divide by median width and multiply by 100.

Window: observation length

Window rows = 5% of analyzed rows, rounded up. For example, 1,000 rows use 50; 101 rows use 6. This is not a hard rule requiring a defect to last more than 5% before it contributes.

A small spike still contributes, but no longer directly defines the whole stripe's worst value. An extreme spike can still raise RMS. The 5% scale is provisional, not a validated universal optimum. No combined quality score is currently assigned.

Only fully measured windows are evaluated. A window containing missing rows is excluded, not filled with zeros. If no valid window exists, the result is “—”.

4. Why does Boundary move the green edges?

Boundary is an image-signal threshold, not a quality score. This diagram illustrates the dark-red signal across a stripe with two dark rims.

The horizontal axis crosses the stripe; the vertical axis is relative dark-red contrast. Green vertical lines illustrate threshold crossings. This concept diagram does not reproduce the complete photo detector, background estimation, or center constraints.

A higher Boundary generally selects a darker, more inward contour, but is not necessarily more correct. First check that green edges follow the intended outer dark-red boundaries. If both edges enclose the same dark rim, the quality numbers may be misleading.

5. Other settings

Boundary signal

Dark-red contrast uses a logarithmic red/green channel ratio. Legacy uses R−(G+B)/2. These signal definitions differ; identical Boundary percentages do not identify the same physical boundary.

Roughness window: 121 px

A one-dimensional box filter averages the preceding 60 points, the current point, and the next 60 to create each orange trend point. Measurements still advance one point at a time. Larger windows generally include longer-scale variations in Rq; keep the setting fixed for comparisons. Endpoint windows are shorter.

Auto tilt correction

Estimate one global sample direction, then measure cross-sections perpendicular to it. Local bending is not straightened. Perspective, lens distortion, and surface warping are not corrected; uncertain estimates remain uncorrected.

Scale: µm/px

Calibrate using a known scale. If 1 px = 2 µm, then 0.3 px = 0.6 µm. Leave blank for pixels. Unit conversion does not improve accuracy. Local v8 percentages are normalized by stripe width.

Relative analysis section: Start / End

When enabled, select percentages of each sample's own length. A 2–98% section excludes approximately 2% at each end. When disabled, use the full sample box. The 5% window refers to the selected analyzed section, not the entire photograph.

Sample length: mm

Optional physical length of the full sample box, used to estimate selected-section length and defects per 10 mm. It is separate from µm/px; the two inputs do not automatically calibrate each other.

Sample search: Tolerant / Strict

Controls sample-box discovery. Tolerant retains more faint candidates; Strict filters more. It is separate from Boundary and does not grade quality. Check that each box contains the left 1 µL and right 2 µL stripes.

Width defect threshold: 25%

The legacy counter compares width with its local moving-average baseline. A deviation exceeding max(2 px, baseline × threshold) for at least three consecutive rows counts as one event. This is separate from the v8 worst-5% RMS and is not its acceptance limit.

Zoom / Fit / Zoom selected sample

These change the display only, not the analysis pixels or measurements. Zoom in to check whether the green boundaries are correctly located.

Profile comparisons

Overlay one sample's 1 + 2 µL stripes, all 1 µL, or all 2 µL, and tick samples to show. Each trace spans its own 0–100% length, not necessarily the same physical distance. Filtering the chart does not remove measurements.

6. Full data and measurement validity

More metric definitions
Width SD / Edge Ra / Relative Rq

SD is width standard deviation. Ra is mean absolute edge deviation from the local trend. Relative Rq = 100 × Rq / mean width. It differs from the local v8 RMS normalized by median width.

Straightness RMS / Center RMS

Straightness fits each edge separately and combines perpendicular residual RMS values. Center RMS fits a straight line to the midpoint trajectory and describes its bending.

Angle difference / Fitted width

Angle difference is the angle between separately fitted left and right lines, mainly describing taper; a small angle does not guarantee local constant width. Fitted width is the perpendicular spacing of the two parallel blue guides.

Raw peaks / Raw contraction and expansion

The most severe deviations at individual valid positions are retained for traceability. Small noisy regions or incorrect detections can amplify these peaks; do not confuse them with window RMS.

Coverage / Undetected / Longest gap

Coverage is the proportion successfully measured; Undetected is the unmeasured proportion; Longest gap is the longest uninterrupted unmeasured span as a proportion of analyzed length. Missing rows can represent a real gap or detection failure, so this is not a direct product breakage rate.

Re-detected / Uncertain / Valid windows

Re-detected rows were confirmed by retrying the original cross-section after an initial failure. Uncertain rows could not be confirmed. Valid windows contain only valid measurements. Complete coverage does not prove boundary correctness.

Defects / 100 px / Defects / 10 mm

These are legacy width-event counts normalized by analyzed length. They are event densities, not the fraction of defective length.

CSV and algorithm versions

Legacy results CSV retains overall metrics. In the new version, Defect CSV exports worst windows, raw peaks, settings, and validity; Profiles CSV contains point-level data. Retain the algorithm version, Boundary, window settings, image scale, and selected section with each result.

Without the original image, check validity before comparing numbers under matched conditions. Poor coverage, misplaced edges, and different image scales can make low values appear reassuring. This guide does not establish validated production acceptance limits.
